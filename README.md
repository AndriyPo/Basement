# Basement renovation concepts

Interactive 2D and 3D comparison of six preliminary three-bedroom apartment layouts.

Open index.html in a browser, or use the GitHub Pages website. No installation, server, or external dependencies are needed.

Includes layout selection, rotation, overhead view, finish palettes, PNG downloads and JSON model export.

Dimensions are preliminary estimates anchored to recorded measurements. This is a planning study, not a construction or permit drawing.

Original basement photographs and private project files are not included.

## Hosting

In GitHub repository Settings > Pages, choose Deploy from a branch, main, / (root), and Save.
